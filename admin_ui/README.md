# Админ-панель NBD

Панель работает на вашем компьютере и управляет ботом на хосте через админ-API, встроенный в бота (`cogs/api_cog.py`).
Есть два режима, переключаются в `admin_ui/.env` параметром `ADMIN_MODE`.

| Режим | Что нужно | Что доступно |
|---|---|---|
| `readonly` | только `DISCORD_TOKEN` (берётся из `.env` бота), хост менять не нужно | серверы, каналы, чат (чтение и отправка от имени бота) |
| `remote` | админ-API на хосте + доступ к нему | всё: плеер, очередь, плейлисты, саундборд, приколы, лента, админ-действия |

## 1. Запуск панели на своём компьютере

1. Установите зависимости: `pip install -r requirements.txt` (из корня проекта).
2. Проверьте `admin_ui/.env` (шаблон — `.env.example`):

       ADMIN_MODE=readonly        # после установки на хост смените на remote
       BOT_URL=http://127.0.0.1:8787
       ADMIN_API_TOKEN=<мастер-ключ из MASTER_KEY.txt>
       UI_PORT=8080

3. Запустите: `python admin_ui/server.py`
4. Откройте http://127.0.0.1:8080

Токен остаётся на вашем компьютере: браузер говорит только с `localhost`, а локальный сервер подставляет токен сам.

## 2. Установка на хост (один раз, когда будете готовы)

1. Загрузите на хост (с сохранением структуры папок):
   - новые файлы: `cogs/api_cog.py`, `cogs/fun_cog.py`, `utils/playlists.py`, `utils/sounds.py`, `utils/mixer.py`;
   - обновлённые: `main.py`, `config.py`, `cogs/music_cog.py`, `cogs/admin_cog.py`, `utils/queue_manager.py`.
   `MASTER_KEY.txt`, `admin_ui/` и локальный `.env` на хост загружать не нужно.
2. Убедитесь, что на хосте установлены `aiohttp` и ffmpeg (уже требуется боту) и `discord.py` версии 2.4 или новее (для опросов).
3. Перезапустите бота. В логе появится `Админ-API слушает 127.0.0.1:8787`.
4. На своём компьютере откройте туннель (порт на хосте наружу не открывается):

       ssh -N -L 8787:127.0.0.1:8787 user@адрес_хоста

   Если у хостинга нет SSH, скажите, какой он: подберём другой способ (например, обратный прокси с HTTPS).
5. В `admin_ui/.env` поставьте `ADMIN_MODE=remote`, перезапустите `python admin_ui/server.py`.

Мастер-ключ вшит в бота как SHA-256 хэш, поэтому доступ работает без каких-либо дополнительных переменных на хосте.

## 3. Доступ для нескольких людей

Да, можно: панель поддерживает несколько одновременных подключений, и события синхронизируются у всех.
Каждый человек запускает панель у себя со своим токеном. Токены задаются в `.env` бота на хосте:

    ADMIN_API_TOKEN=alice:ТОКЕН_ДЛИННЕЕ_16_СИМВОЛОВ
    ADMIN_GUEST_TOKENS=bob:ДРУГОЙ_ТОКЕН,carol:ЕЩЁ_ОДИН

- `ADMIN_API_TOKEN` — полный доступ, включая перезапуск и выключение бота, логи, ошибки.
- `ADMIN_GUEST_TOKENS` — гостевой доступ: музыка, саундборд, плейлисты, чат и приколы, но без вкладки «Админ» (перезапуск, логи, ошибки).
- Имя перед двоеточием попадает в ленту событий: видно, кто что сделал.
- Отозвать доступ: убрать токен из `.env` и перезапустить бота. Мастер-ключ работает всегда и только у вас.
- Каждому человеку придётся открыть SSH-туннель к хосту (или вы настраиваете общий защищённый адрес).

Токены генерируйте случайными, например: `python -c "import secrets; print(secrets.token_urlsafe(24))"`.

## 4. Что есть в панели

- **Обзор:** все серверы бота на одном экране — где бот в голосе, что играет, очередь; пауза/пропуск/выход прямо с карточки.
- **Сервер:** плеер (пауза, пропуск, громкость, повтор, перемешивание), очередь с перетаскиванием, запуск треков/плейлистов/радио, голосовые каналы с участниками, информация о сервере, чат от имени бота (ответы, реакции, закрепление, правка и удаление, файлы и GIF, эффекты текста), модерация (очистка, слоумод, ник бота).
- **Плейлисты:** свои плейлисты на хосте, сохранение текущей очереди в плейлист.
- **Саундборд:** загрузка звуков на хост (кнопка или перетаскивание), запуск поверх музыки, «зайти, сыграть и выйти», поиск, клавиши 1–9, прослушивание у себя.
- **Приколы:** embed-объявления с живым предпросмотром, опросы, «бот печатает», печатная машинка, отложенные сообщения.
- **Лента:** события с фильтрами по типу, серверу и тексту.
- **Админ:** синхронизация команд, перезагрузка модулей, сброс плеера, проверки, статус бота, ошибки, логи с автообновлением и фильтром, каталог команд, перезапуск.

Удобства: палитра команд **Ctrl+K** (переход к серверу или странице, управление плеером), светлая и тёмная тема (🌓), прямые ссылки вида `#server/<id сервера>`, работа на телефоне. Гостевым токенам вкладка «Админ» и модерация не показываются.

## 5. Развлечения для всех участников сервера

Новый ког `fun_cog` добавляет слэш-команды: `/8ball`, `/roll`, `/coin`, `/choose`, `/rate`, `/compliment`, `/joke`.

## 6. Безопасность

- Мастер-ключ в `MASTER_KEY.txt`: храните только у себя, не загружайте на хост. При утечке сгенерируйте новый и замените `MASTER_KEY_HASH` в `config.py`.
- API по умолчанию слушает только `127.0.0.1` на хосте. Не открывайте порт наружу без HTTPS.
- Размер загружаемого звука ограничен `SOUND_MAX_MB` (по умолчанию 10).
